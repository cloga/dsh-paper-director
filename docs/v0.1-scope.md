# v0.1 范围与使用边界

## 已实现的创作闭环

孩子先想故事、按顺序放入照片、填写每张图的对白/动作，再录制或上传**一整段配音**。不要求逐幕录音。

- 本地保存项目、原始素材和不可变版本；修改带版本检查，恢复不覆盖原件。
- 图片支持静态 JPEG/PNG/WebP；录音以实际文件格式探测，不依赖文件名扩展名。支持WAV、MP3、音频M4A/MP4、FLAC、OGG、WebM等已验证解码器支持的类型。
- 本地 Whisper/Vosk 对齐适配器，或由成人明确标记台词时间；缺模型时不假装识别成功。
- 漫画字幕、人物名牌高亮、思考/短句/惊讶气泡；普通镜头硬切，魔法/时间卡过场，中文片头和片尾。
- 自带原创合成星光/提示铃，可关闭或使用已导入的授权音效替换。
- Azure晓晓可生成批准的旁白文字，默认关闭。片头可关联生成的旁白；段内旁白目前建议包含在完整录音中，不宣称任意位置自动TTS混排。
- 真实H.264/AAC MP4预览和导出，原始录音保留。音轨时序以已解码采样顺序为准，异常容器时间戳给出核对提示。
- Agent工具绑定单个作品；对齐等异步任务完成后，通知对应的仍在运行环境中的会话。冷会话不擅自重新创建；成功渲染不触发重复制作循环。
- 页面显示助手可见回复，排除思考过程、工具细节和其他会话历史；助手停下不等于电影完成。
- 停顿剪辑先形成可试听的提案；作者确认后应用，拒绝不改内容。模型不能自行许可删除未确认的声音。
- 反馈可依据正在观看的导出文件及其实际时间索引定位旧版场景，不把电影秒数当原录音秒数。

## 不作的承诺

- 这是原照片/剪纸故事的剪辑与包装工具，不是把静态人物自动生成连续肢体动画的模型。
- ASR输出只是候选，不能保证童声、人名或非对白动作声全部识别正确；提供的人工时标也不证明空白里没有声音。需要试听和作者确认。
- 无对白动作幕当前采用保守默认展示时间；复杂音效动作的精细配图、任意多轨剪辑和批量时间重排不属于这一版。
- 不含公共社区、陌生人交流、儿童独立账号、付费平台或无人监管的学校部署。
- 受限Agent不是完整浏览器/操作系统沙箱。共享DSH登录仍有宿主权限，请在成人监督下使用。

## 网络与费用

媒体探测、对齐、绘图、混音和渲染在本地执行。点击“交给导演助手”会把故事、台词、动作说明及转写文字交给成人配置的DSH模型，该模型可能在云端；不要把它误认为整个系统完全离线。

Azure只接收请求朗读的文字，不接收原始录音。配置仅在Host，工具和网页不接触密钥。每天5000字符的保护限额仅用于本工具旁白请求，不代表模型费用上限；请求结果不确定时不自动重试付费调用。

## 资源与故障

单素材默认100MiB、项目历史素材合计512MiB、原录音最长10分钟、成片最长15分钟。上传按Core/项目限制并发，媒体工作器串行，输出监测为软限额而非操作系统磁盘quota。原始文件不会因恢复旧版本而被删除。

在进程中断、模型不可用、缺字体或结果未能安全保存时，界面应显示未完成，而不是虚报成功。数据库/工作目录应位于本机可信位置并做好备份。

## 测试证据如何理解

测试覆盖真实Core、HTTP、MediaRecorder编解码、MP4播放、剪辑与版本恢复，也分别验证实际DSH SDK API、正式离线安装及原生Loader。匿名示例使用生成的图形与音调；测试中的人工转写、受控Agent回调不冒充真实ASR质量或收费模型推理。具体结果与当前实现状态见相关验证文档。
